# Ultimate Training Modpack – DI Mixup

Modified version of the Ultimate Training Modpack for Super Smash Bros. Ultimate 13.0.4.

This version is based on Training Modpack v7.0.0 and adds a **DI Mixup** option that allows a new DI direction to be selected on every hit instead of keeping the same direction throughout the entire combo.

## Features

* All features from Training Modpack v7.0.0
* Support for Super Smash Bros. Ultimate 13.0.4
* **DI Mixup**

  * Off: normal DI behavior
  * On: a new DI direction is selected on every hit
